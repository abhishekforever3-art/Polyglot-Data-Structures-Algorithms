Extract both schema and data from postgres database:
pg_dump -U postgres postgres > dump.sql

Extract schema only from postgres database:
pg_dump -U postgres -s postgres > dump.sql

Extract data only from postgres database:
pg_dump -U postgres -a postgres > dump.sql
